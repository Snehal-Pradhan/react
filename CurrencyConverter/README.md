### Currency Converter

A simple currency converter built with React and TypeScript.

![App Screenshot](./screenshot.jpeg)

### Features

- **Real-time Conversion:** Fetches live exchange rates for accurate currency conversion.
- **Dynamic Currency Support:** Automatically populates available currencies based on API data.
- **Two-way Swap:** Instantly switch between "From" and "To" currencies with preserved amounts.
- **Type Safety:** Built with TypeScript for robust type checking and reliability.
